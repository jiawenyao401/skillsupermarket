# 从 MCP 推荐指南到一次可核对的 PR 选型

日期：2026-09-09。延续 [增长计划](growth-and-design-plan-2026-09-09.md) 的“具体任务 → 公开报告 → 决定是否接入”假设，不新增文章 URL，也不重新计算原观察期。

## 阻碍与基线

目标是正在给 Claude Code 接入 GitHub 的开发者。原推荐指南虽然有 GitHub 介绍，但正文没有本站报告入口，末尾主要动作是登录后创建评测；读者无法就着一个具体采用任务直接核对现有证据。此为源码和匿名页面确认的入口缺口，不是通过访谈证明的流失因果。

16:50 只读聚合，最近 7 个北京时间自然日（包含今天）：目标指南只有 1 次站内 PV，评测 CTA 0、继续阅读 0；目标 GitHub MCP 报告没有流量行。没有流量行不等于证明无人看过；统计受隐私设置、机器人过滤与来源缺失影响。完整业务日报今天已经执行，不重复生成。

## 本轮交付

只增强既有 `/guides/claude-code-mcp-server-recommendations-2026`：用“读取指定 PR，不评论、不提交 review、不合并”的单一任务，说明如何查看报告时间、版本和告警，再分别核对工具集、底层身份权限与自有测试资源，给出停止接入条件。对应段落直接链接免登录公开报告，先读证据，不必先创建任务。

官方来源采用 [GitHub 远程 Server 文档固定提交](https://github.com/github/github-mcp-server/blob/7d13a7ad6f2a17f351a6d77ce280c85ae1821f4d/docs/remote-server.md)，提交时间 9 月 8 日，9 月 9 日核对。文档确认只读 PR 工具集的地址和远程服务持续更新；这是配置文档核验，**没有连接第三方 MCP、执行 PR 读取/写入或测试任何第三方账号权限**。

16:44 读取的现有 GitHub MCP 报告生成于 9 月 7 日，评测器 3.11.0，存在阻断建议。文章没有改报告、强制重评、覆盖告警或将疑似凭证信号定性为已确认泄露。公开仓库可公开读取，不用它测试私有仓库授权隔离。文档固定提交不等于托管服务运行版本，静态仓库评测不等于运行时审计。

只添加一项可选报告引用及既有样式链接；其他指南不变。无依赖、评分、账号、权限、数据库或采集变更。新指南链接不伪装为评测 CTA；现有聚合不能精确归因指南到报告的点击，不新增个人追踪。

## 验收与停止条件

- 页面原 URL、canonical 和发布时间保留，更新日期改为本轮真实内容更新日；Article 元数据同步。
- 单元回归验证案例边界、固定来源、链接位于注册评测动作之前、其他指南不出现无关报告，以及站内 slug 的完整性。
- 浏览器脚本 `scripts/check-guide-report.mjs` 使用现有 Playwright：七档宽度、两个无脚本场景、键盘导航、完整页面无横滑、JSON-LD、匿名报告锚点；阻断统计和一切业务写请求，不把自测计为增长。
- 初次本机脚本错误地只读第一个 JSON-LD（它是全站 Organization/WebSite，不是 Article），因此日期断言失败；已改为解析所有 JSON-LD 并仍严格要求 Article 和日期匹配，没有删除断言或修改网站来迁就测试。
- 人工审图发现内嵌长地址被原文章容器裁切，文案改为指向固定官方配置文档，并新增段落自身无裁切断言。无脚本场景的动态样式注入等待未完成，退出本轮测试进程后改为直接设置根元素样式并设置有限超时；所有场景完整重验，没有去掉无脚本场景。最终本机 9 项通过、浏览器错误 0；它只验收指南页面，报告导航仍须完整生产候选验证。
- 首次 `tsx` CLI 被沙箱拒绝创建本地 IPC；使用无需该 IPC 的 `node --import tsx --test` 完成专项，并在获准的环境完成原命令全量回归，不当作应用失败或略过测试。
- 生产仍采用隔离 release，排除 main 中待配置的注册保护；只有备份可读、免密 SSH 和回滚版本可用且候选通过验收后切换。

9 月 11 日检查原指南访问与后续意图，9 月 16 日复盘公开报告链路；无目标访问就不继续润色或扩写同类文章，转向发现/索引证据和已准备的合规分发；有访问无继续行为再定位真实卡点。新入口上线不是新增用户或转化提升。既有第三方目录 PR 仍未发送，本轮不重复索取发送授权。
