# 输出日志不能充当采用证据 · 2026-09-08

## 根因与范围

3.12.0 的使用示例检查排除了 `output`，但安装命令检查没有同样限制；而示例通过条件又允许安装证据替代使用证据。结果：标明是日志的代码块，只要出现 `npm install` 或配置中的 `command`，就同时获得安装/示例分，并解除既有反关键词堆砌保护。`stdout`、`stderr`、`log` 内的 JSON/请求结果也会被误读为使用说明。

3.13.0 在安装与使用证据识别之前统一排除显式 `output/stdout/stderr/log/logs` 块，沿用 CommonMark 解析后的语言标记（含大小写、嵌套、长围栏和信息元数据）。保留真正的 shell/console 会话、无语言和 text 命令，以及正常本地/远程 MCP JSON 配置。

这是本站对显式“输出”标记的保守证据分类规则，不是 Markdown 标准规定，也不是已执行命令的真实性证明。作者仍可能重标语言或伪造输入文档；本修复不声称解决所有刷分、提示注入或机器人注册。输出依然参与现有文档长度与结果说明检查，只是不作为可执行采用证据。未更改权重、阈值、风险封顶、置信度或模型提示词。
