## 本轮进入实现的假设

- 问题：本站已有证据报告和五维评分，但缺少可索引、精确匹配“MCP Server 安全扫描 / 评测”意图的入口。
- 实验：上线 `/mcp-server-security-scan`，公开能力与限制，连接真实案例、检查清单和首次评测。
- 成功指标：上线后 7 天内取得至少 1 次非内部页面访问或 1 次评测 CTA；同时不降低评测成功率。
- 停止条件：7 天仍为 0，则不继续堆叠同类页面，改查索引覆盖、搜索需求和站外发现路径。
