# 长 README 证据遗漏：真实报告选型修正

## 使用阻碍与假设

9 月 16 日 context-mode 报告有 2 PV（不能据此推定 2 个用户）。它在 8 月 31 日生成的 3.9.1 报告，将托管 Insight 功能泛化为外部依赖，并建议需要离线运行的用户避开。目标用户是正在判断本地数据处理/平台兼容性是否适合自己的开发者；不能让其因为评测器没读到原文而错误排除项目。

假设：在相同 30,000 字符 README 预算内分配多类证据，能消除安装长章节挤掉边界说明的问题，减少无依据的不适用建议。验证关注原文保留与判断依据，不以分数变高作为成功，也不声称带来转化增长。若确定性边界、既有回归失败，或模型抹掉真正的联网限制，不上线；历史报告不自动覆盖。
