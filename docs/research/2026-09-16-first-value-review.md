## 5. 复算方式与交付性质

使用既有 `traffic_daily` 聚合表。在只读连接中复算固定窗口，缺失来源行按“无记录”列为 0，而不是补造事件：

```sql
BEGIN READ ONLY;
SET LOCAL statement_timeout = '10s';
SELECT source,
       COALESCE(SUM(page_views), 0) AS page_views,
       COALESCE(SUM(evaluation_cta_clicks), 0) AS evaluation_cta_clicks,
       COALESCE(SUM(guide_continuation_clicks), 0) AS guide_continuation_clicks
FROM traffic_daily
WHERE date >= DATE '2026-09-09' AND date < DATE '2026-09-16'
GROUP BY source ORDER BY source;
SELECT path, source, SUM(page_views) AS page_views,
       SUM(evaluation_cta_clicks) AS evaluation_cta_clicks
FROM traffic_daily
WHERE date >= DATE '2026-09-09' AND date < DATE '2026-09-16'
GROUP BY path, source ORDER BY path, source;
ROLLBACK;
```

用户/任务时间戳使用相同北京时间边界的 `timestamptz`（显式 `+08`），仅 `triggered_by = 'authenticated-user' AND user_id IS NOT NULL` 算用户任务；首评按已完成任务的最早创建时间计算，与现有日报口径一致。业务字段可用性及滚动日报沿用 [growth-report.ts](../../scripts/growth-report.ts)。
