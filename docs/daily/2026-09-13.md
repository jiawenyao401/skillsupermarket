发现一个可复现的承接阻碍：189 个项目中 178 个已有报告，但首页粘贴已收录 GitHub MCP 地址仍提交 `/evaluate`，匿名返回 307 到登录。此前通用搜索按名称/描述/标签检索，不能可靠按项目来源查到对应报告。负责人已确认报告可以看懂，因此优先疏通取得自己需要的报告的路径。

假设：先提供与访客候选项目匹配的公开报告，能够在注册前交付价值；只有需要新评测时再登录。现有数据不能量化此前登录门槛造成的流失，也不能逐人关联查找、阅读与注册，不能计算精确转化率。

旧 Vercel 地址本轮有限时探测未取得 HTTP 响应，也没有已关联的项目配置；无法据此判断重定向是否成功。正式 robots/sitemap 可访问不代表已被搜索引擎收录。此缺口已记录，未以重复网络排查替代本轮功能交付。
