# 报告时间、版本与复评入口 · 2026-09-08

## 基线与交付

北京时间 10:38 生产只读复核：183 个有效 Skill 中 172 个有报告，但没有一份采用当前 3.13.0 引擎。此前公开报告把版本放在折叠的方法区，`evaluatedAt` 没有展示，缺失版本还会猜作 `1.x`；已有报告页面也缺少保留项目的复评入口。这会让访客难以区分项目最近更新、报告生成时间和当前引擎。

在报告主结论前加入服务端渲染的“报告时间与版本”：展示数据库保存的时间（固定北京时间、语义化 `time` 标签）、报告记录的引擎以及当前运行引擎。仅做精确版本一致性说明，不把不同版本一律称为旧版/过期（运行服务可能回滚），不把版本一致解释为项目代码或安全状态实时有效。

旧报告元数据只接受本站三段数字版本格式；顶层版本与 methodology 版本冲突、字段无效或缺失时明确提示，不输出任意原始字符串、不替换为当前版本，也不再猜 `1.x`。时间无记录或非有效 Date 时不伪造时间。折叠方法区复用相同版本解释。

有可验证来源时提供同站 `/evaluate?skill=编码后的slug` 链接；无来源时不显示入口。沿用已有登录后的 returnTo、来源预填与额度检查，关闭链接预取；仅点击不创建任务、不扣额度，用户仍需在工作台确认并提交。复用现有 CTA 路径分类和隐私约束，不增加账户/身份追踪或新付费逻辑。

## 范围边界

- 无数据库查询或迁移增量，无依赖/锁文件变更，无评分、认证、Worker、缓存失效策略或权益调整。
- 新组件为 Server Component，不新增客户端脚本。既有报告分数、图示与版本不变，不自动重评或调用模型。
- 新入口并非免登录/免验证通道；现有未配置的注册保护仍在独立待发布版本中，不能夹带上线。
- 版本元数据不是源代码 commit 签名或审计证明，不能以本功能宣称解决证据来源完整性。
